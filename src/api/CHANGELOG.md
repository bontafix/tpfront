# История изменений API модулей

## [Рефакторинг] - 2025-12-07

### 🎯 Цель
Разделение монолитного файла `requests.js` (1302 строки) на модули по сущностям для улучшения структуры и поддерживаемости кода.

### ✨ Добавлено

#### Новые модули:
1. **apiClient.js** (189 строк)
   - Базовый axios клиент с настройками
   - Interceptors для обработки авторизации
   - Функции `makeRequest()` и `makeGetRequest()`

2. **students.js** (333 строки)
   - 40+ функций для работы с учениками
   - Управление профилями студентов
   - Домашние задания студентов
   - Результаты и аналитика
   - Импорт/экспорт данных

3. **teachers.js** (152 строки)
   - Управление профилями учителей
   - Финансовые операции учителя
   - Доходы и расходы
   - Задачи учителя

4. **lessons.js** (338 строк)
   - Получение уроков (по месяцам, неделям, дням)
   - Создание различных типов уроков
   - Управление темами и проблемами урока
   - Домашние задания уроков
   - Новости

5. **auth.js** (112 строк)
   - Регистрация и авторизация
   - Проверка авторизации
   - Смена пароля
   - WebSocket токены

6. **finance.js** (71 строка)
   - Заработок за различные периоды
   - Аналитика по студентам
   - Финансовая отчетность

7. **notifications.js** (35 строк)
   - Уведомления учителей
   - Уведомления студентов

8. **groups.js** (88 строк)
   - Управление группами
   - Групповые уроки
   - Домашние задания для групп

#### Файлы документации:
- **README.md** (234 строки) - подробная документация всех модулей
- **USAGE.md** (документация по использованию)
- **CHANGELOG.md** (этот файл)
- **index.js** - главный экспортный файл

### 🔧 Миграция

**Никаких изменений в существующем коде не требуется!**

Все импорты продолжат работать:
```javascript
// ✅ Работает как и раньше
import { getStudentById } from '@/api/requests'
```

**Для нового кода рекомендуется:**
```javascript
// ✅ Рекомендуется - более явно
import { getStudentById } from '@/api/students'

// ✅ Рекомендуется - короче
import { getStudentById } from '@/api'
```
