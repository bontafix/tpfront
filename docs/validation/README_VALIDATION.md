# 🎯 Улучшение валидации формы регистрации

## Быстрый старт

### Что изменилось
Форма регистрации (`/src/components/user/v-register.vue`) теперь имеет полноценную валидацию с визуальной обратной связью.

### Основные улучшения
✅ Валидация имени пользователя (минимум 3 символа)  
✅ Проверка формата email через regex  
✅ Контроль длины пароля (минимум 8 символов)  
✅ Новое поле подтверждения пароля  
✅ Сообщения об ошибках под полями  
✅ Визуальная подсветка ошибок  
✅ Блокировка кнопки при невалидной форме  
✅ Поддержка темной темы

## 📦 Что в коробке

### Валидация
- Имя пользователя: обязательно, минимум 3 символа
- Email: обязательно, корректный формат
- Пароль: обязательно, минимум 8 символов
- Подтверждение пароля: обязательно, должно совпадать
- Чекбокс о возрасте: обязательно

### Сообщения об ошибках
Понятные и полезные сообщения под каждым полем:
- "Имя пользователя обязательно для заполнения"
- "Введите корректный email адрес"
- "Пароль должен содержать минимум 8 символов"
- "Пароли не совпадают"

### UX
- Валидация при потере фокуса (blur)
- Красная подсветка полей с ошибками
- Анимация появления сообщений
- Блокировка кнопки при невалидной форме
- Показ/скрытие паролей
- Toast-уведомления
