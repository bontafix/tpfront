## 🧪 Тестовые сценарии

### Что нужно протестировать вручную:

1. **Пустая форма**
   - [ ] Нажать "Продолжить" без заполнения
   - [ ] Должны появиться все ошибки

2. **Невалидный email**
   - [ ] Ввести "test" в поле email
   - [ ] Должна появиться ошибка "Введите корректный email адрес"

3. **Короткое имя**
   - [ ] Ввести "ab" в поле имени
   - [ ] Должна появиться ошибка о минимальной длине

4. **Короткий пароль**
   - [ ] Ввести "1234567" (7 символов)
   - [ ] Должна появиться ошибка "Минимум 8 символов"

5. **Несовпадение паролей**
   - [ ] Ввести "password123" и "password456"
   - [ ] Должна появиться ошибка "Пароли не совпадают"

6. **Показ/скрытие пароля**
   - [ ] Нажать на иконку глаза
   - [ ] Пароль должен стать видимым/невидимым

7. **Темная тема**
   - [ ] Переключить на темную тему
   - [ ] Проверить цвета ошибок

8. **Валидная форма**
   - [ ] Заполнить все поля корректно
   - [ ] Отметить чекбокс о возрасте
   - [ ] Кнопка должна стать синей и активной
