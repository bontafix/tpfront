# 🧪 Инструкция по тестированию формы регистрации

## Как открыть форму регистрации

1. Запустите приложение: `npm run dev`
2. Перейдите по адресу: `/register` или нажмите "Регистрация" на главной

---

## ✅ Тестовые сценарии

### Сценарий 1: Пустая форма
**Действия:**
1. Откройте форму регистрации
2. Нажмите кнопку "Продолжить" без заполнения полей

**Ожидаемый результат:**
- ❌ Кнопка неактивна (disabled)
- ❌ При нажатии ничего не происходит

---

- 📝 Под полем текст: "Введите корректный email адрес"

### Сценарий 3: Корректное заполнение

**Действия:**
1. Очистите все поля
2. Введите корректные данные:
   - Имя: `testuser`
   - Email: `test@example.com`
   - Пароль: `password123`
   - Подтверждение: `password123`
3. Отметьте чекбокс "Я подтверждаю, что мне исполнилось 18 лет..."

**Ожидаемый результат:**
- ✅ Все поля без красной подсветки
- ✅ Кнопка "Продолжить" стала синей
- ✅ Кнопка активна (можно нажать)

---

### Сценарий 4: Показ/скрытие пароля

**Действия:**
1. Введите пароль: `mypassword`
2. Нажмите на иконку 👁️ справа от поля

**Ожидаемый результат:**
- 👁️ Пароль становится видимым
- 👁️‍🗨️ Иконка меняется на "перечеркнутый глаз"

**Действия:**
3. Нажмите на иконку еще раз

**Ожидаемый результат:**
- 🔒 Пароль снова скрыт
- 👁️ Иконка вернулась к "глазу"

---

### Сценарий 5: Попытка отправки невалидной формы

**Действия:**
1. Заполните форму частично:
   - Имя: `test`
   - Email: `test@test.com`
   - Пароль: `12345678`
   - Подтверждение: `87654321` (другой!)
2. Отметьте чекбокс о возрасте
3. Нажмите "Продолжить"

**Ожидаемый результат:**
- 🔴 Поле "Подтвердите пароль" подсвечено красным
- 📝 Сообщение "Пароли не совпадают"
- 🔔 Всплывающее уведомление: "Пожалуйста, исправьте ошибки в форме"
- ❌ Форма не отправлена

---

### Сценарий 6: Успешная регистрация

**Действия:**
1. Заполните форму корректно:
   - Имя: `newuser123`
   - Email: `newuser@example.com`
   - Пароль: `secure_password_123`
   - Подтверждение: `secure_password_123`
2. Отметьте чекбокс о возрасте
3. Нажмите "Продолжить"

**Ожидаемый результат:**
- ✅ Запрос отправлен на сервер
- ✅ При успехе (200/201):
  - 🔔 Уведомление: "Регистрация успешна! Теперь войдите в систему"
  - 🔄 Перенаправление на страницу логина
  - 📝 Поля логина автоматически заполнены
- ❌ При ошибке:
  - 🔔 Уведомление с текстом ошибки от сервера

---

### Сценарий 7: Темная тема

**Действия:**
1. Откройте форму регистрации
2. Переключите приложение в темную тему
3. Введите невалидные данные для вызова ошибок

**Ожидаемый результат:**
- 🌙 Все элементы адаптированы к темной теме
- 🔴 Ошибки отображаются в цвете #FF7474 (светло-красный)
- 🔴 Поля с ошибками имеют корректный фон для темной темы
- 📝 Метки полей читаемы

## 📝 Заметки для тестировщика

1. **Все проверки выполняются на фронтенде** - это первая линия валидации
2. **Бэкенд должен дублировать все проверки** - для безопасности
3. **Сообщения об ошибках** должны быть понятными и помогать пользователю
4. **Темная тема** должна быть комфортной для глаз
