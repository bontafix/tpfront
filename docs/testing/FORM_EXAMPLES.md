## 🎨 Цветовая палитра

### Светлая тема
```
Обычные поля:
  Фон:    #FFFFFF (var(--custom-white))
  Рамка:  стандартная
  Текст:  var(--custom-black-text)

Поля с ошибками:
  Фон:    #FFEDED (светло-розовый)
  Рамка:  #FF3A3A (красный)
  Текст:  #FF3A3A (красный)

Кнопка неактивна:
  Фон:    белый
  Текст:  серый
  Курсор: not-allowed

Кнопка активна:
  Фон:    синий
  Текст:  белый
  Курсор: pointer
```

### Темная тема
```
Обычные поля:
  Фон:    var(--custom-black)
  Рамка:  стандартная
  Текст:  rgba(255, 255, 255, 0.87)

Поля с ошибками:
  Фон:    rgba(255, 58, 58, 0.1)
  Рамка:  #FF7474 (светло-красный)
  Текст:  #FF7474 (светло-красный)

Метки полей:
  Текст:  rgba(255, 255, 255, 0.87)

Сообщения об ошибках:
  Текст:  #FF7474 (светло-красный)
```

```css
  }

```

## 🎭 Интерактивные элементы

### Иконка показа/скрытия пароля
```
Пароль скрыт:  👁️  (eye.svg)
Пароль видим:  👁️‍🗨️ (eye-off.svg)

При клике:
  password → text
  text → password
```

### Чекбоксы
```
Не отмечен: ☐ (styled-checkbox)
Отмечен:    ☑ (styled-checkbox checked)
```

### Кнопка
```
Неактивна: ⬜ (white) + disabled
Активна:   🟦 (blue) + clickable
```

## 📱 Адаптивность

### Desktop (>768px)
- Форма по центру
- Полная ширина полей
- Большие отступы

### Mobile (<768px)
- Форма на всю ширину
- Адаптивные отступы
- Читаемые размеры шрифтов
