# Функция автоматического входа после регистрации

## 📋 Описание

После успешной регистрации пользователь может автоматически войти в систему без необходимости вручную нажимать кнопку "Продолжить" на форме входа. Логика авторизации переиспользуется из формы входа, избегая дублирования кода.

## 🔒 Безопасность

Данные (логин и пароль) передаются через **router.state** вместо query параметров URL:
- ✅ Не видны в адресной строке браузера
- ✅ Не сохраняются в истории браузера
- ✅ Не попадают в логи сервера/прокси
- ✅ Автоматически очищаются при обновлении страницы

## 🎯 Режимы работы

### 1. Скрытый автовход (по умолчанию)
```javascript
const AUTO_LOGIN_MODE = 'true'
```
- **Форма входа полностью скрыта**
- Автоматически вызывается функция входа
- Пользователь не видит процесс (только уведомление об успехе)
- Пустая страница во время входа (быстрый переход)

### 2. Видимый автовход
```javascript
const AUTO_LOGIN_MODE = 'visible'
```
- Форма входа скрыта
- Показывается простое сообщение "Выполняется автоматический вход..."
- Минималистичный дизайн без яркого оформления
- Пользователь видит что происходит вход

### 3. Ручной вход
```javascript
const AUTO_LOGIN_MODE = false
```
- Форма входа автозаполняется данными
- Пользователь должен вручную нажать кнопку "Продолжить"
- Текущее поведение (для обратной совместимости)

## 🛠️ Настройка

### v-register.vue

Изменить константу в начале `<script setup>`:

```javascript
// Настройка автоматического входа после регистрации
const AUTO_LOGIN_MODE = 'true' // 'true' | 'visible' | false
```

## 📝 Реализация

### Измененные файлы

#### 1. `src/components/user/v-register.vue`

**Добавлено:**
- Константа `AUTO_LOGIN_MODE` для управления режимом автовхода
- Передача данных через `router.state` вместо `query` параметров

```javascript
// Передача данных безопасно через router.state
const state = {
  username: form.value.username,
  password: form.value.password1
}

if (AUTO_LOGIN_MODE) {
  state.autoLogin = AUTO_LOGIN_MODE
}

await router.push({
  name: 'login',
  state: state  // Данные НЕ попадут в URL
});
```

#### 2. `src/components/user/v-login.vue`

**Добавлено:**
- Получение данных из `history.state` (router.state)
- Автоматический вызов `submitForm()` при наличии флага `autoLogin`
- UI индикатор для видимого режима автовхода
- Обратная совместимость с query параметрами

```javascript
// Получаем данные из router.state
const routerState = history.state

if (routerState?.username) {
  form.value.username = routerState.username
}
if (routerState?.password) {
  form.value.password = routerState.password
}

// Автоматический вход
if (routerState?.autoLogin && form.value.username && form.value.password) {
  await submitForm()
}
```

## 🎨 UI компоненты

### Индикатор автовхода (видимый режим)

Простой минималистичный блок с сообщением:
- 📝 Текст "Выполняется автоматический вход..."
- 🎨 Светло-серый фон без яркого оформления
- 🌙 Поддержка темной темы
- ✨ Без анимаций и спиннеров (чистый дизайн)

## ✅ Преимущества решения

1. **Безопасность** - пароль не попадает в URL
2. **Переиспользование логики** - вся авторизация остаётся в форме входа
3. **Гибкость** - три режима работы на выбор
4. **Простота** - одна константа для переключения режима
5. **UX** - плавный переход после регистрации
6. **Обратная совместимость** - fallback на старый метод с query

## 🔄 Алгоритм работы

```
1. Пользователь регистрируется (v-register.vue)
   ↓
2. Успешная регистрация (статус 200/201)
   ↓
3. Создаётся state с username, password, autoLogin
   ↓
4. router.push({ name: 'login', state: {...} })
   ↓
5. Форма входа монтируется (v-login.vue)
   ↓
6. onMounted получает данные из history.state
   ↓
7. Автозаполнение формы
   ↓
8. Если autoLogin === 'visible' → показать индикатор
   ↓
9. Вызов submitForm() (вся логика авторизации)
   ↓
10. Редирект на главную страницу (teacher/student)
```

## 📚 Примечания

- Данные в `router.state` автоматически очищаются при обновлении страницы
- Fallback на query параметры сохранён для обратной совместимости
- UI индикатор показывается только в режиме `'visible'`
- Вся логика авторизации (WebSocket, редиректы, cookies) остаётся без изменений
