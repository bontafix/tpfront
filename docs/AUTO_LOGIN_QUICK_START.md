# Быстрый старт: Автовход после регистрации

## ⚡ Как использовать

### Включить/выключить автовход

Откройте файл `src/components/user/v-register.vue` и найдите строку:

```javascript
const AUTO_LOGIN_MODE = 'true' // 'true' | 'visible' | false
```

### Режимы

| Значение | Описание | Когда использовать |
|----------|----------|-------------------|
| `'true'` | **Скрытый автовход** | Лучший UX - форма скрыта, пользователь сразу попадает в систему |
| `'visible'` | **Видимый автовход** | Показывается простое сообщение о входе (для информирования) |
| `false` | **Ручной вход** | Только автозаполнение, требуется нажать кнопку |

### Примеры

#### Скрытый автовход (рекомендуется)
```javascript
const AUTO_LOGIN_MODE = 'true'
```
✅ Пользователь регистрируется → форма скрыта → автоматически входит → переходит на главную

#### Видимый автовход (с сообщением)
```javascript
const AUTO_LOGIN_MODE = 'visible'
```
✅ Пользователь регистрируется → видит простое сообщение "Выполняется вход..." → переходит на главную

#### Отключить автовход
```javascript
const AUTO_LOGIN_MODE = false
```
✅ Пользователь регистрируется → переходит на форму входа → видит автозаполненную форму → нажимает "Продолжить"

## 🔒 Безопасность

Пароль **НЕ** передаётся через URL! Используется безопасный механизм `router.state`.

## ❓ FAQ

**Q: Почему пароль не виден в адресной строке?**  
A: Данные передаются через `router.state`, а не через query параметры URL.

**Q: Что произойдет если обновить страницу?**  
A: Данные из `router.state` автоматически очистятся, форма будет пустой (безопасно).

**Q: Можно ли настроить задержку перед автовходом?**  
A: Да, измените значение в `v-login.vue`:
```javascript
await new Promise(resolve => setTimeout(resolve, 100)) // 100ms по умолчанию
```

**Q: Где логика авторизации?**  
A: Вся логика остаётся в функции `submitForm()` файла `v-login.vue`. Дублирования кода нет.
